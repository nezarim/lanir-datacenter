# Lanir DC Group - קבוצת לניר דאטה סנטר

דף נחיתה דו-לשוני (עברית/אנגלית) לקבוצת לניר דאטה סנטר — שותפויות דאטה סנטר לבעלי נכסי תעשייה בפריפריה בישראל. הדף מציג את מודל השותפות PropCo-OpCo, נתונים כלכליים, יתרונות תחרותיים וטופס יצירת קשר.

## תכונות

- **דף נחיתה מקצועי** — עיצוב מודרני עם hero section כהה, כרטיסים, אנימציות ואפקטים חזותיים
- **תמיכה דו-לשונית** — מתג עברית/אנגלית עם החלפת כיוון RTL/LTR בזמן אמת
- **סקירת שירותים** — קולוקיישן, Build to Suit, Edge as a Service, AI & HPC
- **מפרט טכני** — זמינות 99.995%, קירור N+1, אבטחה 24/7, אנרגיה סולארית 50%, Carrier-Neutral, UPS
- **הסמכות** — ISO 27001, SOC 2, Tier III, Green Energy
- **מודל עסקי** — שלושה שלבים: נכס, הקמה ומימון, רווח הדדי
- **נתונים כלכליים** — הכנסות צפויות, EBITDA, הטבת מס, והכנסה לבעל הנכס
- **יתרונות תחרותיים** — אנרגיה סולארית בעלות נמוכה, אגירה ב-$150/kWh, תשתית תקשורת עצמאית, בנייה מודולרית, הגנה לבעל הנכס, מענקים ממשלתיים
- **טופס יצירת קשר** — שם, טלפון, אימייל, מיקום, שטח ופרטים נוספים
- **אנימציות גלילה** — אלמנטים מתגלים בגלילה באמצעות IntersectionObserver
- **רספונסיבי** — תצוגה מותאמת למובייל עם תפריט hamburger

## טכנולוגיות

- HTML/CSS/JS בקובץ יחיד — ללא frameworks
- Google Fonts — Heebo (עברית) + Inter (אנגלית)
- CSS Custom Properties (משתנים)
- CSS Grid + Flexbox
- IntersectionObserver לאנימציות גלילה
- GitHub Pages לאירוח

## מבנה הפרויקט

```
lanir-datacenter/
  index.html          # דף הנחיתה המלא (HTML + CSS + JS)
```

## התקנה והרצה

הפרויקט הוא קובץ HTML יחיד סטטי. לפתיחה מקומית:

```bash
# אפשרות 1 — פתיחה ישירה
open index.html

# אפשרות 2 — שרת מקומי
npx serve .
# או
python3 -m http.server 8000
```

## אבטחה

- **דף סטטי בלבד** — אין צד שרת, אין מסד נתונים, אין אחסון מידע רגיש
- **טופס יצירת קשר** — שולח נתונים באמצעות `fetch` ל-endpoint חיצוני (לא מוגדר בקוד הנוכחי, `handleSubmit` מטפל בהצגת הודעת הצלחה)
- **אין אימות משתמשים** — דף פומבי לחלוטין
